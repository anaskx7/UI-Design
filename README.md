# UI Design Showcase

A modern React + Vite landing page concept built as a visually rich promotional interface for a digital marketing and travel-inspired brand experience.

## Overview

This project showcases a sleek UI composed of:

- a clean top navigation bar
- a bold promotional headline and supporting copy
- a horizontally scrollable card gallery with travel-themed imagery
- colorful action buttons and rounded glassmorphism-inspired styling
- responsive layout designed for a premium marketing landing page feel

## Tech Stack

- React
- Vite
- Tailwind CSS
- Lucide React icons

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js (v18 or newer)
- npm

### Installation

```bash
npm install
```

### Run the App

```bash
npm run dev
```

Then open the local Vite URL shown in the terminal to view the project.

### Production Build

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Scripts

```bash
npm run dev      # start the Vite development server
npm run build    # create a production build
npm run preview  # preview the production build
npm run lint     # run ESLint checks
```
